# 极简/现代（minimal-modern）

## 视觉特征
- 大留白、单一强调色、细线边框
- 无装饰元素，靠排版/间距建立层次
- 中性底色（白/浅灰/纯黑），内容优先

## 技术要点（tech）
- 留白：间距成体系（4/8/16 倍率），`padding` 大方
- 强调色：只保留 1 个 `--accent`（其余 accent-2 系弱化或同色系）
- 边框：1px 细线（`--border` 低对比），hover 时加深
- 层次：用字号/字重/间距分级，不用颜色堆层次
- 阴影：极浅或不用（`box-shadow` 0 1px 2px 级）

## 反模式（别做什么）
- 信息密度过低（留白过度，一屏没内容）
- 缺视觉层次（全同字号同色，找不到重点）
- 对比度不足（浅灰字配白底，WCAG 不过）
- 偷偷加装饰（装饰一旦开闸，极简就破了）

## 素材/资源建议
- 字体：系统字体栈或简洁无衬线（Inter/系统默认，零版权风险）
- 图标：线性 icon set（授权或自绘）

## 参考案例
- Linear、Vercel、Apple 官网（留白+单一强调色+细线）
