# 暗色科技（dark-tech）

## 视觉特征
- 深色渐变面板、发光强调色、科技感细节
- 介于极简与赛博之间：克制用发光，整体冷静
- 深灰/深蓝黑底 + 一个高亮强调色

## 技术要点（tech）
- 底色：深色渐变面板（`linear-gradient` 深灰→更深），层级用亮度差区分
- 强调：发光只给重点元素（按钮/焦点/选中态），`--accent-glow` 统一控制
- 边框：深色底上的 1px 半透明边框（`rgba(255,255,255,.1)` 系）
- 文字：正文用高亮度灰白（非纯白，纯白在暗底显刺眼）
- 焦点态：明显 focus ring（发光边框）

## 反模式（别做什么）
- 暗色文字在暗底（`--card-foreground` 掉进暗色系）
- 发光过多散焦（满屏发光 = 没有重点）
- 动画过长（科技感动效 >300ms 变拖沓）
- 纯黑底（#000 底配高亮文字对比过猛，用深灰更舒适）

## 素材/资源建议
- 字体：无衬线系统栈或 Inter 类（授权确认）
- 纹理：极浅噪点/网格底纹（可选，别喧宾夺主）

## 参考案例
- Vercel Dashboard、GitHub Dark、Linear 暗色模式（深灰底+单色发光强调）
