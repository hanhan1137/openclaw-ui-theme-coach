# 像素/游戏（pixel-game）

## 视觉特征
- 低分辨率块状像素、硬边直角、无抗锯齿
- 深色底 + 高饱和主色（如 MC 草绿/泥土棕），材质感强
- 按钮呈 9-slice 浮雕块状，悬停/按下有物理位移感

## 技术要点（tech）
- 字体：Zpix 等点阵字体，按 12px 倍数取字号最清晰；`font-family` 兜底 monospace
- 纹理：PIL 块状噪声生成 32×32 纹理图（先画 8×8 随机小块 → `Image.NEAREST` 最近邻放大，泥土/石头块状感），`background-repeat`
- 按钮：9-slice 浮雕按钮图，`border-image: url(...) 3 fill / 3px / 0 stretch`
- 图片渲染：`image-rendering: pixelated`（禁平滑缩放）
- 圆角一律 0，边框 2-3px 实线

## 反模式（别做什么）
- 渐变背景（破坏像素硬边感）
- 抗锯齿字体/高分辨率纹理（出戏）
- 逐像素雪花噪声纹理（像素风要块状，用最近邻放大的小块噪声）
- 过度圆角（像素风=直角）
- 阴影/发光过多（像素阴影应是硬边偏移，不是柔光）

## 素材/资源建议
- 字体：Zpix（个人/教育免费，商用单产品需付费，发布前确认授权）
- 纹理/按钮：PIL 自绘，零版权，可安全开源
- 图标：像素风 sprite（注意来源授权）
